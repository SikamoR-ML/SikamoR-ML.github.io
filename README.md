# Hooked on ML

Интерактивное резюме Алексея Подшибякина в духе Dota 2.

Сайт: https://sikamor-ml.github.io/

Пудж притягивает разделы хуком. Навигация: кнопки или клавиши 1–5. Звук включается вручную; анимацию можно отключить. Поддерживается prefers-reduced-motion, мобильный экран и печать. Факты и метрики из CV; игровые названия — оформление.

Статический HTML/CSS/JS без сборки. GitHub Pages: main / (root).

Dota 2 принадлежит Valve. Неофициальный фан-проект. Иллюстрация создана с ИИ.

## Живая 3D-модель

Пудж отображается через официальный Sketchfab Viewer API 1.12.1. Модель: “Dota 2 | Pudge animated”, sportmajes52, CC BY 4.0: https://sketchfab.com/3d-models/dota-2-pudge-animated-3e0d07fe19334fc1ac4d3cbe0ff8f516

Модель можно вращать и приближать мышью/касанием, кнопка сбрасывает ракурс. Скрипт ищет idle и hook/cast-анимации по названиям в модели и включает бросок при смене разделов. Отключение анимаций останавливает модель. При недоступности Sketchfab резюме остаётся доступным, показывается иллюстрация и повтор загрузки. Требуется WebGL и соединение со Sketchfab.

Персонаж и исходные игровые материалы принадлежат Valve. Локальная AI-иллюстрация — резервное изображение.
