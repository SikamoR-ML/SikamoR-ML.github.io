# Ресурсы фан-резюме

Dota 2, персонаж Пудж, иконки способностей и предметов — Valve Corporation. Иконки получены с официального CDN Valve (cdn.cloudflare.steamstatic.com/apps/dota2/images/dota_react/). Это неофициальный некоммерческий фан-проект для учебного задания.

3D-модель: Dota 2 | Pudge animated, sportmajes52, CC BY 4.0.
https://sketchfab.com/3d-models/dota-2-pudge-animated-3e0d07fe19334fc1ac4d3cbe0ff8f516
https://creativecommons.org/licenses/by/4.0/
Модель встроена через официальный Sketchfab Viewer API 1.12.1. Используются оригинальные анимационные клипы pudge_meathook_start/end, pudge_dismember_start/mid, pudge_idle, pudge_spawn и victory.

Короткие звуковые реплики:
- Pudge hook, файл vo_pudge_pud_ability_hook_10.mp3: https://www.myinstants.com/en/instant/pudge-hook-68042/
- Fresh Meat, файл butcher.mp3: https://www.myinstants.com/instant/fresh-meat/embed/

Цепь, удары, шум Rot и интерфейсные сигналы синтезируются Web Audio; они не являются оригинальной звуковой дорожкой Dota 2. Короткие реплики используются как звуковые цитаты в фан-интерфейсе. Звук включается пользователем.

Названия игровых предметов служат метафорой реального опыта. «Scepter of Mentoring» — придуманное название артефакта для преподавания. Локации и карта условные. Роли в списке команды — сценарий интерфейса, не сведения о работе пользователя.

Факты CV и метрики — по резюме Алексея Подшибякина. Числа HP, MMR и стаж, которых нет в CV, не приписываются автору.
